# 藍甕日記 Indigo Diary

*A collaborative project by roylin1003 and Claude.*

藍染發酵的小玩具：在甕面畫圈攪拌、把布拖進甕裡浸染（放手拉起來氧化）；蓼藍的蒅、木灰灰汁、麩和石灰。
純 HTML5 單檔，不需安裝、不需伺服器。

**▶ 立即遊玩**：https://indigo-diary.roynexus.com/

> 目前為 **ALPHA 測試版**，版面與數值仍在調整中。歡迎回報手感問題。

## 操作

在甕面畫圈攪拌；把布拖進甕裡再放手。
